What is being tested

Tension you can learn,
not certainty you can solve.

01

Pre-sampled fate

Each run receives one hidden bust budget. Fixed simulation ticks consume it, keeping outcomes reproducible and frame-rate neutral.

02

Readable pressure

The visible signal contains error, but remains correlated with the actual hazard. Attention should improve decisions over time.

03

Bounded stakes

Stakes use fictional credits, payout begins at 1×, and reaching the 8× ceiling automatically banks rather than forcing a loss.
